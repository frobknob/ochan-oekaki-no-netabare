o-chan no oekaki logic (おーちゃんのおえかきロジック) is a lovely nonogram puzzle game for the WonderSwan, released by SunSoft in 2000. if you're here you know exactly what this is and don't want to read this crap.

the thing is, i like picross/nonogram games way too much. after finishing all the Mario Picross games, then the Picross NPs, then basically any other version i could find, i eventually ran across the WonderSwan. it's a ridiculously cool console that didn't get enough attention — your favorite retro-game-youtuber-person will surely give you the details so i don't have to.

anyway, the game is in Japanese and i couldn't find any solutions when i got stuck on 中級 #18.

as a bad gamer that doesn't know when to give up, i used all of my laziness and Claude tokens to figure out this ROM and come up with a friendly helper. hopefully there's at least one other person out there who is also lazy and/or stuck on this game.

if you're somehow still interested, here's how it happened:

1. me: crap, i'm stuck. internet has no answers.
2. claude: why does the internet have no answers? find answers.
3. claude: “i can do that, no problem, like 10 minutes.”
(24 hours and some Anthropic revenue later)
4. claude: static analysis: NEVER ENOUGH TOKENS nom nom. dynamic analysis: kept hitting walls. finally got there with memory analysis inside a running MAME session + Capstone for x86 disassembly. result: this page.
5. me: i, for one, welcome our robot overlords
